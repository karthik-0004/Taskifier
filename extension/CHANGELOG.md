# Changelog

All notable changes to the "taskifier" extension will be documented in this file.

## [0.0.1] - 2026-07-26

### Added

* Initial Release of the Taskifier VS Code Extension.
* **Personal Mode:** Offline support for standalone developer tracking.
* **AI Configuration:** Support for OpenRouter, OpenAI, Anthropic, Gemini, and Ollama.
* **Git Commit Scanning:** Automatically fetch today's Git activity.
* **AI-Enhanced Summaries:** Transform technical commits into professional updates.
* **Export Options:** Markdown export, PDF generation, and Email report delivery.
* **VS Code Sidebar:** Integrated Webview dashboard for task management.
* **CLI Commands:** Full terminal suite (`t start`, `t update`, `t submit`, etc.).
